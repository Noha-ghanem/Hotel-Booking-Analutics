# Hotel Dashboard Analysis

## Project Overview
This project focuses on analyzing hotel booking and revenue data using Microsoft Excel to explore reservation trends, cancellation rates, and customer demographics through an interactive dashboard.

## Tools & Technologies
- Microsoft Excel (Pivot Tables, Slicers, Charts)
- Data Cleaning & Transformation
- Data Visualization

## Project Files
- Excel Dashboard (.xlsx)
- Raw Dataset (.csv)
- Dashboard Screenshot

## Dashboard Preview
Screenshot of the dashboard (`Hotel Dashboard Analysis`) is available in the repository.

## Key Analysis
- Overall booking KPIs, total revenue, and cancellation rate tracking
- Booking status breakdown by hotel type and lead time
- Monthly revenue trends and top booking countries analysis
